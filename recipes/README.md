# レシピファイルの形式

1レシピ = 1 Markdown ファイル。ファイル名は `YYYY-MM-DD-<slug>.md`。

## frontmatter

```yaml
---
title_ja: 塩麹（手作り）
title_en: Homemade Shio Koji
category: koji          # koji / low-temp / coffee / nuts / airfryer / daily
temp_c: 60              # 温度（℃）。関係なければ省略可
minutes: 480            # 所要時間（分）。発酵など長時間はそのまま書く
season: 秋              # 季節（任意）
region: 山形            # 地域（任意）
source_url: https://www.threads.com/...   # 出典（収集した実例の場合）
source_author: "@username"                # 出典の投稿者
---
```

## 本文

- 材料
- 手順
- コツ・注意点
- 暮らしの背景（季節・地域・どんな場面のものか）— 海外の人に「やってみたい」「日本に行ってみたい」と思ってもらうための大事な部分

## サンプル

`2026-10-25-shio-koji.md` が手本です。
