# IKIGAI

**Japanese recipes for a deliberate life.**

日本の丁寧な暮らしのレシピ集。麹、低温調理、コーヒー、ナッツのロースト、エアフライヤーなど、
日本では普通の、日々の暮らしの工夫を集めて、海外の人にも届けるためのプロジェクトです。

A collection of everyday Japanese recipes and techniques — koji fermentation,
low-temperature cooking, coffee, roasted nuts, air-fryer cooking and more —
the small, careful practices of daily life in Japan, shared with the world.

## 仕組み / How it works

- レシピは `recipes/` に Markdown ファイルで保存します（1レシピ = 1ファイル）
- 各ファイルは frontmatter（タイトル日英・カテゴリー・温度・時間・出典など）を持ちます
- 書き方は [recipes/README.md](recipes/README.md) を参照
- 将来: Markdown 群を JSON 化してアプリ／サイトから誰でも見られる形にします

## カテゴリー / Categories

- `koji` — 麹・発酵
- `low-temp` — 低温調理
- `coffee` — コーヒー
- `nuts` — ナッツ・ロースト
- `airfryer` — エアフライヤー
- `daily` — 日々の暮らし

## 出典について / Sources

SNS 等から集めた実例は、要点のみを記録し、元投稿の URL と投稿者名を必ず出典として残します。
Collected examples are summarized, never copied in full, and always credited
with the original post URL and author.
